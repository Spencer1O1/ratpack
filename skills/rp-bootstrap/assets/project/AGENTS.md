# Agent instructions

Follow [the contributor workflow](docs/development.md). Before work, read the
project's relevant requirements/design, assignment, and current handoff.
Shared project settings and merge policy are in `ratpack.json`; this developer's
pack coordinator/staffing are in ignored `ratpack.local.json`. Shared integration
authority, task owners, and dependencies are in the tracker or explicit human
assignments. A local pack does not grant merge rights.
