# Agent instructions

Follow [the shared contributor workflow](docs/development.md). Read the project's
requirements, design, and current handoff before editing. Assignments and the
delegation limit are recorded in `ratpack.json`.

- Coordinate ownership before edits; use a separate branch/worktree per task.
  Preserve other contributors' files, branches, and uncommitted work.
- The coordinator delegates bounded implementation within user authorization.
  Workers implement and hand off; independent reviewers review; only the current
  integration owner merges. Names do not grant authority.
- Report exact checks/results, review findings, remaining work, and next owner.
  Do not confuse implementation completion with integration or release.
